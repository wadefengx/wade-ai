# <需求名> · 接力板

> **接力协议**（给任何 Agent / harness，不需要别的配置）
> 1. 开工：读完本文件，再用 `git status`、`git log --oneline -10` 核对。文件和 git 对不上时以 git 为准，并在日志里写明。
> 2. 别人标着「进行中」的项不要直接接手：先问用户那个 Agent 是否还在跑；问不到时，看日志最后的时间和未提交的改动，确认已经中断了再接，并在日志里写明。
> 3. 认领：在要做的那一项后面写「进行中：<harness> / <模型> · 时间」。
> 4. 每完成一项：验证 → commit（有授权时）→ 勾掉并附 SHA → 在日志最上面加一条：时间 · harness / 模型 · 做了什么、怎么验证的、下一棒要注意什么。
> 5. 收尾：去掉自己的「进行中」，更新「当前状态」，在日志最上面写一条标「已收尾」的记录和下一棒要做什么。只记在你自己工具里的计划、todo 和记忆，下一个 harness 看不到，要写进本文件。
> 6. 「约定」里的规则对每一棒都有效。用户给出新规则时，马上写进去。
> 7. 有 `.ai/memory/sim.md` 时，改规则、测试或脚本之前先查相关记录，不重走撤回过的路。同一个问题第二次出现，或者一个做法被撤回，就在那里记一条：为什么改、改之前预期什么、实测结果。
